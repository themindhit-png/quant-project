## Стратегия F2
Семь рукавов (`SLEEVE_SCALES`: ml8=2, остальные 1): listing (шорт молодых перпов 7–90 дней + хедж лонгом BTC/ETH/BNB/SOL/XRP), core (качество тренда 336ч, квантиль 20%), ml3/ml7 (LightGBM 3д/7д, без признака возраста, вселенная ≥90д, топ-150, 30%/30%), ml8 (LightGBM 8ч, пересчёт 01/09/17 UTC, возраст ≥180д, инверсия волы, q=0.2), fchg (контрарно к 24ч-изменению фандинга), fcarry (carry по 72ч фандингу). Дальше: EMA 0.5 → волтаргет 0.6%/день → множитель риска K → капы (лонг 2%, шорт 1.5%, мажоры 30%) → нейтральность → гросс ≤2× → полоса ребаланса 0.5. Ребаланс 01:10/09:10/17:10 UTC, PostOnly 3×90с, потом маркет.

## Данные и издержки исследования
Binance USDT-M 1h, 860 символов (с делистнутыми), 2020-01..2026-08. Комиссии 5.5/2 бп (тейкер/мейкер), проскальзывание зависит от оборота, мейкер-доля 70%. Исполнение в бэктесте мгновенное по закрытию бара.
