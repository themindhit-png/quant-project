- **Воспроизведение на старых предсказаниях** (`research/phase4_check_oldpred.py`, `logs/phase4_check_oldF2.log`; сетка 804 симв., END 2026-08-31): lag 0 → Sharpe **2.53** (= эталон F2 исследования, точно); lag 1 ч → 1.94. DEV lag 0: 2.82 / 2.65 (новые предсказания на сетке 819 симв. чуть слабее в 2023-2024; для сравнения кандидатов неважно — все варианты считаются на одной сетке).
- **Слабый HOLD (0.10) — настоящий, не артефакт новой инфраструктуры.** Помесячно (lag 1 ч): март −0.2, апр. −1.2, май −2.2, июнь −2.4, июль +4.6, авг. +3.2, сен. +0.2, окт. −1.4 %. Вывод: у F2 с весны 2026 заметный спад качества; в 2026 книга почти без преимущества после задержки и издержек.
- **Найдена ошибка DSR (исправлена).** `trials_std()` искал результаты попыток только в корне — там остался 1 файл (27 строк, sd 0.39), остальные 13 файлов в `archive/out`. С полным набором (≈490 строк, sd 0.49) порог SR0 растёт 1.19 → 1.51. Кроме того, Sharpe попыток отбора считались при lag 0 / ×1, а DSR считался на lag 1 ч — разные единицы. Исправлено до первого кандидата: DSR считается на DEV **lag 0 ×1** (`DSR_SC`), sd — по всем файлам (корень + `archive/out`, без дублей). DSR базы: **0.990** (lag 0). Для справки: на lag 1 ч было бы 0.91 (ниже 0.95). Это уточнение способа расчёта, а не правило «под результат»: кандидатов ещё не было.
- Остальное в `cmp` проверено прогоном «F2 против F2»: Δ 0, p = 1.0, вердикт ОТКЛОНЁН (как и должно быть).
