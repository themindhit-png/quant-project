# PLAN v3 — от демо до максимума: проп-фирмы, лестница, личный счёт (2026-09-09, после раунда 4 ревью)

Все числа — из прогонов бота на истории 2022-01..2026-08 (бот-в-цикле, 25 скользящих стартов каждые 2 месяца, мейкер-филлы 70 %, реальные цены и фандинг Binance) и из исследования. «p25» — четверть худших стартов, «медиана» — половина. Решения принимаются по p25, медиана — хороший исход. Ожидаемый форвард выбранной книги ≈ медиана семейства финалистов (Sharpe 2.2–2.3 до стрессов), а не её собственный бэктест (PBO 0.60). Все прогоны финальной версии бота (правило отключения v2, кап low-cap) завершены: логи `logs/rollF2v2_*`, `hF2_pure_eq_v4.log`.

## 0. Решение одним абзацем

Книга **F2** (7 рукавов; хэши конфигурации — только в PREREG.md). Порядок жёсткий: **(1) демо 3–4 недели + одновременно канарейка на своём Bybit-счёте $300–500 (обязательно — только так измеряется настоящая доля мейкер-филлов); (2) первый и единственный «слепой» риск — Mubite 2-step $10 000 с тремя надбавками (цель 8 %, просадка 10 %, сплит 90 %) за $176, режим bold; (3) на VPS — тест книги на ставках фандинга Bybit (`exp30`), потому что ~50 % результата книги — фандинг, измеренный на Binance; (4) всё, что дороже $176, — только после (1)–(3) и после прогонов HyroTrader во всех режимах.** Вторая фирма — HyroTrader c надбавкой Swing (без неё скользящая дневная просадка ломает книгу) или PTB после малого теста; один счёт на фирму; два счёта одного бота — **одна ставка, не диверсификация** (корреляция путей ≈ 1), польза только контрагентская. Потолок — $200k на фирму (Mubite: программа масштабирования до $1M — удвоение каждые 120 дней при +10 %). Личный счёт — тот же бот, пресет `personal`: волтаргет 1.0 %/день → CAGR ≈ 55 % при просадке ≈ 14 %; «максимальная» настройка 1.5 %/день → CAGR ≈ 71 % при просадке ≈ 22 % и худшем дне ≈ −6 %.

## 2. Бот, пред-регистрация, демо и канарейка

* Версия v4 (раунд 4): тесты 44/44; PREREG.md — 6 режимов с хэшами (`EXPECTED_CONFIG_HASH` → бот не стартует при несовпадении), правило отключения ml8 **v2** (чистый вклад за вычетом издержек, пороги 0.5/0), автоматическая проверка фандинга и базиса Bybit↔Binance, кап low-cap с прокси, выплаты как денежный поток.
* **Демо, 3–4 недели** (бесплатно, любая из двух фирм): проверяем (1) фандинг начисляется (иначе книга F и её хэш); (2) `last_fill_seconds` ≤ 900 с; (3) `n_positions ≈ n_targets` 100–160; (4) `dvol_norm` 0.50–0.70 %, `clip_share` < 5 %; (5) ни одного «REBALANCE ABORTED»; (6) `funding_basis`: корреляция ≥ 0.7. Все метрики — в `/status` и в Telegram.
* **Канарейка — обязательна, параллельно с демо**: личный Bybit-счёт $300–500, `FIRM=personal`, `VT_TARGET_DVOL=0.006`, BASE 1.0. Цель — `maker_share_real` и `adverse_bps_real` из реальных филлов (демо их завышает по построению). Критерий: мейкер-доля ≥ 50 %, неблагоприятный отбор ≤ 3 бп → смелый режим челленджа допустим; иначе — calm/moderate и дневная книга по правилу 2 PREREG.
* **exp30 на VPS** (после демо-недели, ~1 ч): ставки Bybit против Binance. Пока не сделан — покупается только первый Mubite.
* Хостинг: VPS ради аптайма (2 vCPU / 4 GB), Telegram-алерты, копия состояния + выгрузка в Telegram, API-ключ «trade + read» без вывода, one-way mode, cross-margin.

## 4. Экономика максимума и что она означает

Доход трейдера = размер × выплаты %/год × 0.85–0.90:

| Капитал под управлением | p10 (10.3 %) | p25 (21.7 %) | медиана (28.7 %) | «все по рынку» (13.7 %) |
|---|---|---|---|---|
| $10k | $0.9k/год | $1.9k | $2.5k | $1.2k |
| $100k | $9k | $19k | $25k | $12k |
| $200k (одна фирма) | $18k | $38k | $50k | $24k |
| **$400k (две фирмы)** | **$36k** | **$76k** | **$100k** | $48k |
| $450k (+PTB $50k) | $41k | $85k | $113k | $54k |

**Два счёта — одна ставка.** Оба счёта торгует один бот по одним сигналам в одни минуты: корреляция путей ≈ 1, вероятность одновременного пробоя обоих полов равна вероятности пробоя одного (в 25 стартах на истории — 0/25, но это одна книга, а не два независимых наблюдения). $400k — это одна книга на $400k, разложенная по двум контрагентам; выигрыш от второй фирмы — только контрагентский (одна не заплатит — вторая заплатит) и лимит $200k на пользователя. Год с выплатами 4 % (худший из 25) на $400k — $14k.

## 5. Личный счёт (без правил фирмы)

Тот же бот, пресет `FIRM=personal` (единственный пол — собственный стоп 25 % скользящей просадки, дневного стопа нет, капы шире: гросс 3.5×, позиция 3 %/2 %), `MODE=funded`, `NOTIONAL_BASE=equity`. Фандинг на реальном счёте начисляется всегда. Измерено (exp28, движок исследования, мейкер 70 %, 2022–26):

| Волтаргет | Sharpe | CAGR | MDD | худший день | оборот, издержки/год | режим PREREG |
|---|---|---|---|---|---|---|
| 0.6 %/день | 2.38 | 32.6 % | −10.0 % | −3.0 % | 290×, 10.8 % | канарейка |
| 0.8 %/день | 2.45 | 44.4 % | −11.9 % | −3.5 % | 361×, 13.5 % | — |
| **1.0 %/день (рекомендуемый)** | 2.46 | **54.5 %** | **−13.8 %** | −4.4 % | 424×, 15.8 % | `personal_vt10` |
| **1.5 %/день («максимальная»)** | 2.32 | **71.3 %** | **−22.1 %** | −6.1 % | 530×, 19.8 % | `personal_vt15` (стоп 35 %) |
| 1.0 %/день, все ордера по рынку | 1.49 | 29.2 % | −20.2 % | −4.1 % | 33 % издержек | стресс |

Как читать: дальше 1.5 %/день идти нет смысла — Sharpe уже падает (издержки растут с оборотом), плечо упирается в кап 5×, а просадка 22 % — это уровень, где владелец обычно выключает бота на дне. При p25-Sharpe (1.0–1.2) доходности делятся примерно на два, просадки — нет. Правила: канарейка $300–500 первые 3–4 недели → основной капитал на 1.0 % → через 3 месяца метрик в норме — по желанию 1.5 %; держать на бирже только торговый капитал; выводить прибыль выше плана раз в месяц; PREREG-правила остановки те же (3 отрицательных месяца → стоп и разбор). Мульти-актив снят с повестки (REPORT §5k).

## 6. Чек-лист до первой покупки

1. Демо ≥ 14 дней: в Telegram каждый день приходит «Фандинг за сутки: … (N расчётов)», N > 0 → F2; иначе — книга F и её хэш.
2. `last_fill_seconds` медиана ≤ 900 с; `n_positions ≈ n_targets`; `dvol_norm` 0.50–0.70 %; `clip_share` < 5 %.
3. Канарейка: `maker_share_real` ≥ 0.5, `adverse_bps_real` ≤ 3 → bold; иначе calm/moderate.
4. Ни одной ошибки данных/модели; состояние пережило перезапуск.
5. `EXPECTED_CONFIG_HASH` задан (PREREG, режим challenge_bold); алерты Telegram работают.
6. Отложен резерв на вторую попытку ($176).
