# Отчёт: аудит MUBITE-LADDER v3.6 и новая система PROP-SLEEVES v4

Дата: 2026-09-08. Автор: Claude (агент Hyperagent). Адресат: ревью Opus 5 и владелец проекта.
Все цифры воспроизводимы скриптами из папки `proj/` (перечень в конце). Данные: Binance USDT-M perps, 860 символов (включая делистнутые), 1h, 2020-01-01..2026-08-31; фандинг и premium index по всем символам. Bybit API из песочницы гео-заблокирован, поэтому исследование — на Binance-панелях; Bybit использован для калибровки спредов по тикам (public.bybit.com) и для проверки переносимости листинг-эффекта (launchTime).

## 0. Вердикт коротко

1. Бэктест v3.6 (+16.45% CAGR) невалиден: позиции вне текущей вселенной никогда не закрываются (`prices` строится только по `close.columns`, `execute_orders` молча пропускает символы без цены) — в прогоне число позиций росло 81→376 при ~70 целях. Реплика стратегии на чистых данных за 5.25 года: **CAGR −14.2%, Sharpe −0.49, MDD −69%**; по годам −16/−38/−30/+9/+35/−16. Стратегия отброшена.
2. Простые кросс-секционные факторы (тренд, моментум, carry, реверсал, low-vol, объём) на ликвидных альтах 2021–2026 после честных издержек — нулевая игра: gross-Sharpe лучших ≤1.0, оборот 100–450x/год съедает 10–48%/год.
3. Найдено три источника, которые вместе дают устойчивый результат out-of-sample 2022-01→2026-08 (параметры не подбирались на этом окне, ML обучался walk-forward помесячно с embargo):
   * структурный дрифт новых листингов (шорт 7–90 дней после листинга vs лонг мажоров): относительно BTC от дня 3: −7% (7д), −21% (30д), −39% (60д), n=595, hit-rate 61–85% по когортам;
   * качество тренда 336ч (core) — противофазен ML (корреляция −0.36…−0.38);
   * LightGBM-ранкер на 29 признаках с целью «доходность минус фандинг» на 3 и 7 дней: rank-IC положителен **каждый месяц** 2022–2026 (по годам 0.07/0.07/0.07/0.11/0.11 для 3д; 0.09/0.08/0.08/0.13/0.13 для 7д).
   * Портфель A+C+ML3+ML7 (единая книга, мейкер 70%, band 30%, EMA 0.5): **Sharpe 1.38, CAGR 30%, dvol 1.08%, MDD −19%, все годы 2022–2026 положительны**; с волтаргетом 0.6%/день и лев ≤3: Sharpe 1.23, CAGR 18%, worst day −4.2%.
4. Монте-Карло челленджа на реальных часовых доходностях портфеля (block bootstrap): без оверлея провалы 14–42%; с CPPI (K = base·min(1, буфер/(0.5·допуск))) провалы ≈0% ценой времени. Лучший режим: **статичная просадка (Mubite или HyroTrader Swing) + base 1.0 + CPPI 0.5 → проход 76–83%, провал 0–0.1%, остальные ещё живы к 1000-му дню; медиана 194–281 день; выживание funded-счёта за год ≈100%, выплаты ≈13–14%/год**. Trailing-просадка HyroTrader Standard структурно хуже (после каждой выплаты буфер сжимается — «ловушка выплат»).
5. Бот переписан (v4): рукава как модули, риск-движок с пресетами фирм (static/trailing полы, CPPI, дневной троттл/халт, VT, капы, стражи notional/margin/low-cap), исполнение PostOnly→market с полным закрытием любых позиций вне целей, стопы на шорты, харнесс «бот-в-цикле» на исследовательских панелях.
6. **Дополнение 2026-09-09 (§5c): найден и исправлен дефект волтаргета** — рекурсивная формула `lev ← lev·target/realised` по заплечёванным доходностям с отстающим окном превращала VT в маятник между клипами (плечо 0.05 — 35% времени, 3.0 — 20%). Дефект был и в исследовательском движке, и в боте. После исправления (`lev = target / вола незаплечёванной книги`): дневная книга честно даёт Sharpe 1.20–1.26 в исследовании (1.65 в харнессе бота), а **пятирукавная книга с 8-часовым ML-рукавом (имена ≥180 дней, обратно-волатильные веса) — 1.67–1.91 в исследовании на всей сетке параметров и 2.24–2.44 в харнессе бота (CAGR ~30%, MDD −9%, все годы в плюсе)**. «Хрупкость» 8h-комбинации из п.10 §5b была артефактом дефектного VT. Пятирукавная книга — новый продакшн-кандидат; её цена — оборот ~470×/год и зависимость от доли мейкер-филлов (при чисто тейкерском исполнении Sharpe ~0.9–1.1).

## 1. Что было не так в v3.6 (см. AUDIT_bot.md)

* Зомби-позиции (критично) — описано выше; тот же код в main.py и main_fixed.py.
* Оборот 202x/год — структурный: 87% оборота на границах 00/12 UTC (churn квантильных корзин сигнала mean/std 336h), а не «дрожание около полосы». Перевод пересчёта на 12ч не помог бы.
* NET-GUARD активен 69% времени — следствие зомби-ног; волтаргет недооценивал риск по той же причине.
* Издержки харнесса: 2 бп константа. По тикам Bybit медианный полный спред: <$1M/сут 3.7 бп, $1–3M 2.0, $3–10M 1.7, $10–50M 1.55, $50–200M 1.0, >$1B 0.03 → для ликвидного ядра 2 бп не фантазия, для хвоста — занижено. В новой модели издержек slippage = max(1, 8·(t24/1e6)^−0.35) бп (≈3× измеренного полуспреда) + комиссии 5.5/2.0 бп.

## 3. Структурные источники и ML

* Листинг-дрифт (exp3/7/11): event study и стратегия описаны выше. Хвост шортов катастрофичен без капов (день −41% при равных весах 1/15): нужны малые веса (≤1.5% equity на имя), стоп 30% на шорт, исключение имён с ростом >30%/24ч, хедж мажорами (корзина альтов хуже: 0.21 vs 0.57). Топ-признаки: age_d, vol720, beta720, r2160, r1440, fund720. Цель без фандинга давала −21.7%/год фандинга в портфеле → исправлено (цель = доходность − фандинг).

## 5b. Скорость прохода: что реально её определяет (exp10g, exp10h, rolling real-bot)

1. **Утечки объясняют «Sharpe 2.06»** (exp15): чистый сигнал 0.23 → +look-ahead 1 бар 1.01 → +survivorship 0.49 → +без фандинга/2бп → **вместе 2.05, все годы в плюсе**.
2. **Выпуклый риск (K ∝ буфер над полом) НЕ ускоряет** ни в бутстрапе (Mubite DD10: медиана 179→182д), ни на реальных путях бота (обе фазы 234→326д, halts 2→5 из 50 фаз): после просадки риск падает пропорционально, счёт долго выползает. На trailing-полах — ещё хуже.
3. **Реальные пути бота (25 стартов 2022–2026, обе фазы, v2 ML):** Mubite 8+5/DD10 flat base 1.0 — медиана 234 дня (p75 323), ≈87% успеха, halts в стартах 2023-01/2023-07/2025-07; HyroTrader Swing 10+5/DD10 — медиана 375 (p75 647). Бутстрап-MC недооценивает длину просадок 2023-го.
4. **Опция перезапуска меняет оптимум** (exp10h, bot-кривая, сбор $154, abandon при буфере ≤30% допуска): flat 1.5 → медиана 93 дня до funded (p75 165, p90 233), P(≤180д) 79%, 1.9 попытки, сборы $298; flat 2.0 (c=0.25) → **52 дня (p75 92, p90 140), P(≤180д) 94%, 2.6 попыток, $404**; 2.5 → 43 дня, $546. Смелая плоская политика с готовностью сдать и перекупить челлендж — самый быстрый путь; ограничение — кэш на попытки. Funded-стадия: перезапуска нет → base 1.0–1.5 (выживание 100%, выплаты 15–22%/г; реальные пути 2024–25: 19–43%/г, медиана 15.5%).
4b. **Реальные пути бота с опцией перезапуска** (25 стартов, обе фазы, Mubite 8+5/DD10, сбор $154, restart_from_rolling.py): base 1.0 — медиана 246 дней до funded, P(≤180д) 40%, 1.1 попытки, $177; base 1.5 + сдача при буфере ≤30% — 142 дня, P(≤180) 58%, 1.8 попытки, $277; **base 2.0 (c=0.25) + сдача ≤30% — 117 дней (p75 195, p90 314), P(≤90) 33%, P(≤180) 66%, P(≤365) 94%, 1.8 попытки, $275**; неудачные попытки при смелой политике сдаются за 12–32 дня. HyroTrader Swing base 1.0 — 431 день, P(≤180) 9%. Бутстрап-MC (52 дня) оптимистичнее реальных путей (117) — в отчёт идут реальные пути.
5. **Выбор фирмы — Mubite Two-Step с аддонами «цель 8%» и «+2% просадки» (~$154):** статичный пол 10% от стартового баланса, цель 8%+5% (вместо 10%+5%), нет правила low-cap (наш листинг-рукав шортит молодые монеты), нет consistency-правила, боты разрешены; на реальных путях быстрее HyroTrader Swing в 1.6 раза. Обязательное условие — письменное подтверждение API-доступа (Bybit demo key) к челлендж-аккаунту. HyroTrader Swing — второй трек позже (потолок $1M), с листинг-рукавом, отфильтрованным по капитализации ≥$100M или отключённым.
6. В бот добавлены: выпуклый режим (K_MAX, BASE_SCALE_P2 — не рекомендуется), правило перезапуска ABANDON_FRAC (флэт + латч + уведомление).
7. **ML v3 — вывод:** rank-target отклонён (IC 0.128 vs 0.087, но портфель 0.89 vs 1.54: книга живёт на хвостах и величине, Spearman-IC — не та метрика). Regression v3 на 40 признаках: исследовательский Sharpe 1.71 vs 1.54 при MDD −16.4% vs −11.1%; на реальных путях бота (Bybit-совместимый набор без order-flow): flat 1.0 — медиана 229 дн, но 6 halt'ов во 2-й фазе (v2: 2); bold — 116 дн / P(≤180) 75% / 1.6 попытки vs v2 117 / 66% / 1.8. Итог: **деплоим v2** (устойчивее при разных политиках); v3 остаётся кандидатом после реального демо-опыта. Order-flow признаки не нужны (IC без них тот же).
8. Финансовый план (лестница счетов, сроки, выплаты) — PLAN.md.

## 5c. Диагностика хрупкости 8h-книги → дефект волтаргета → новая продакшн-книга (exp20–20i, 2026-09-09)

1. **Симптом.** Соседние конфиги (вес 8h-рукава 2.0 vs 2.5, smooth 0.5) равны до 2024 включительно (2022: +58.9% vs +57.6%), а с 2025 расходятся помесячно на ±10% (2025-09: +5.4/−6.4; 2025-11: −7.7/+3.6; 2026-02: +15.4/−0.8); корреляция дневных доходностей двух почти одинаковых книг: 0.95–0.98 в 2022–23, **0.02 в 2025**.
2. **Ложный след — «лотерея молодых монет».** Атрибуция 2025-01..2026-08: 70% Σ|PnL| — когорта монет с первым баром ≥ 2024-07 (500 из 804), разрыв good−bad почти полностью в ней (+$9 987 vs −$1 150). Лечение ML8-рукава фильтром возраста ≥180д + обратно-волатильными весами (R5) сузило разброс сетки до 1.48–1.98, но 4 из 16 пертурбаций всё ещё падали до 0.8–1.2 (2025 ≈ 0). Контроль jump-риска (кап 0.5–0.75% на молодые имена, шорт-стоп 25%) **вредит везде**: дневная книга 1.50 → 0.99 (кап) / 0.77 (стоп); молодые имена — двигатель прибыли, а тесные стопы по шортам разрушительны (whipsaw). Для дневной книги фильтр возраста ≥180д в ML-рукавах тоже вреден (1.54 → 1.00–1.25): альфа дневных моделей живёт в именах 30–180 дней.
3. **Механизм найден (exp20e–20g).** Дневная книга, которую лишь «подтрагивают» каждые 8ч, теряла Sharpe 1.54 → 0.75 при росте издержек всего +1.5%/г; эмуляция «держать позиции без сделок» давала 0.05. Путь плеча волтаргета: **lev на нижнем клипе 0.05 — 35% времени, на верхнем 3.0 — 20%, 440 дней с изменением >25%/день** (и в дневном движке тоже). Формула `lev ← lev·target/dvol`, где dvol — вола уже заплечёванных доходностей за отстающее 30-дневное окно, — неустойчивая рекурсия: при тихом окне плечо умножается каждый ребаланс до клипа, затем окно наполняется высоковолатильными днями и плечо обваливается до 0.05; на 8-часовом шаге — в 3 раза быстрее. Та же формула стояла в боте (`risk.update_lev`).
4. **Исправление.** `lev = target / realised vol НЕзаплечёванной книги` (доходности делятся на действовавший множитель lev·K), без рекурсии; в боте — по дневным доходностям equity с журналом множителей `mult_daily` (VT_SMOOTH — опциональная EMA). Legacy-режим сохранён в bt.run как `vt_mode='recursive'` для воспроизводимости старых чисел. Тесты бота: 26/26 (добавлены проверки VT и весов ML8 против исследования, совпадение до 1e-13).

## 5l. Раунд 4 ревью Opus: фандинг Bybit, правило отключения v2, low-cap в харнессе, личный счёт

**Фандинг Bybit (главное возражение).** Из среды разработки все домены Bybit API (api.bybit.com, api.bytick.com, testnet, .nl) отдают CloudFront «access from your country blocked» — историю ставок Bybit здесь получить нельзя.
