# Руководство владельца бота (одна версия, обновлено 2026-10-28)

Это единственная инструкция. Всё, что здесь не написано, — не нужно. Старые инструкции и пресеты лежат в `archive/` и не используются.
Команды вставляются в Termius (подключение к VPS netcup) как есть, по одной строке.

---

## 0. Честно о рисках
- Бот торгует статистическую стратегию. На истории 2022-2026 выбранные настройки ни разу не провалили челлендж и не слили funded-счёт,
  но **гарантий нет**: 2026 год был слабее прошлых, а живое демо в сентябре-октябре 2026 было в минусе (−6 %).
- Все цифры прибыли ниже — по истории. В жизни закладывайте **примерно половину**.
- Свои деньги рискуем один раз: взнос за первый челлендж ($10k со всеми опциями ≈ $176).

## 1. План (что и в каком порядке)
1. **Бесплатная проба Mubite (Free Trial)** — проверить подключение бота, подсчёт дней, письма фирмы. Денег не стоит.
2. **Купить Mubite Two-Step Pro $10 000 со всеми тремя опциями** (цель 8 %, просадка 10 %, доля 90 %) ≈ $176.
   Если денег меньше — порядок замен: $10k только с опцией «просадка 10 %» ≈ $132; $5k со всеми ≈ $104; $5k с «просадкой 10 %» ≈ $78.
   **Опция «просадка 10 %» обязательна всегда** (без неё в 12-17 % историй счёт сливался).
3. Фаза 1 (цель +8 %) -> фаза 2 (цель +5 %): обычно 3-5 месяцев вместе, в медленных случаях до 7.
4. Funded $10k: выплата **раз в 28 дней**. Первая выплата возвращает взнос. Все выплаты **копим на следующий счёт**.
   Когда в кабинете появляется кнопка масштабирования (+10 % прибыли за 90 дней), нажимать — счёт растёт на +25 %.
5. Накопили ≈ $1 760 -> **закрываем $10k и покупаем $200 000 со всеми опциями** (по истории — через 7-12 месяцев funded).
   Почему не лесенкой 25k -> 50k -> 100k: каждая ступень = новый челлендж на 4-5 месяцев без выплат; лесенка в 2 раза хуже.
6. Funded $200k: выплата раз в 28 дней, масштабирование до $300k (лимит Mubite на человека). **Все выплаты — на свой счёт Bybit.**
7. Свой счёт Bybit: второй бот, риск выше (1.5 %/день), всё реинвестируется.

По истории (на половину не умножено): $200k funded примерно через 21 месяц от покупки первого челленджа; за 3 года ≈ $135 000 вам.

## 2. Правила Mubite, которые нельзя нарушать (подробно — `docs/FIRMS.md`)
- **Один счёт Mubite с этим ботом одновременно.** Два счёта с одной стратегией = «account rolling», провал всех счетов. Поэтому $10k закрываем
  ДО покупки $200k.
- В кабинет Mubite входить **только из Беларуси, без VPN**, всегда с одного устройства/страны. Один аккаунт на человека. Страна в профиле — настоящая.
- **Не трогать API-ключ**: не удалять, не менять права, не создавать новый ключ без письма фирмы. Ключ живёт 93 дня — продлевать по ссылке
  из письма Mubite (бот напомнит в Telegram за 10 дней).
- Не менять баланс субаккаунта вручную, не торговать на нём руками.
- Перед выплатой все позиции должны быть закрыты, пока выплату проверяют — не торговать (это делает команда `pause`, см. п. 6).
- Бот ваш собственный: если фирма попросит доказать — показать репозиторий (история git).

## 3. Подготовка (один раз)
1. Обновить код бота на VPS:
   ```
   cd /root/quant-project && bash ops/deploy.sh
   ```
   В конце должно быть «/status ответил». Если нет — пришлите вывод в чат.
2. Bybit: по инструкции Mubite (страница «Trading platforms») создать **демо-субаккаунт** без истории и ключ API с правами Read-Write.
   Ключ и секрет вставить в бота:
   ```
   bash ops/stage.sh keys
   ```

## 3а. Бесплатная проба Mubite (7 дней) — проверка механики, не прибыли
Правила пробы: цель 5 %, просадка 10 %, дневной 5 %. Подключить ключ демо-субаккаунта пробы (`bash ops/stage.sh keys`), затем:
```
bash ops/stage.sh trial 10000
```
За 7 дней проверить в кабинете Mubite и прислать скриншоты в чат:
1. сделки видны, баланс в кабинете = equity в `bash ops/bot.sh status`;
2. **счётчик торговых дней растёт** (если за 3-4 дня он 0 — сообщить: это блокирует покупку);
3. нет нарушений правила «3 % на сделку»;
4. дневная просадка в кабинете ≈ та, что видит бот.
После пробы — свой демо Bybit до покупки: ключ своего демо (`bash ops/stage.sh keys`) и `bash ops/stage.sh phase1 10000`.

## 4. Старт челленджа (фаза 1)
После покупки и подключения ключа в кабинете Mubite:
```
bash ops/stage.sh phase1 10000
```
(для счёта $200k — `bash ops/stage.sh phase1 200000`). Бот соберёт настройки, перезапустится и напишет в Telegram «запущен».
Дальше ничего делать не нужно. Проверить состояние в любой момент:
```
bash ops/bot.sh status
```

## 5. Переход фаз
- Когда цель достигнута, бот **сам закрывает все позиции и останавливается** и пишет «🎉 ФАЗА 1 ПРОЙДЕНА». Ничего не торговать руками.
- Ждите письма Mubite о фазе 2. Если вам дали **новый субаккаунт/ключ** — сначала `bash ops/stage.sh keys` (только записывает ключи). Потом:
  ```
  bash ops/stage.sh phase2 10000
  ```
- После фазы 2 («🎉 ФАЗА 2 ПРОЙДЕНА»): KYC, договор, письмо о funded-счёте. По инструкции Mubite подключить ключ funded-счёта
  (`bash ops/stage.sh keys`, если ключ новый), затем:
  ```
  bash ops/stage.sh funded 10000
  ```

## 6. Выплата (раз в 28 дней, funded)
1. `bash ops/bot.sh pause` — бот закрывает все позиции; через 1-2 минуты в Telegram «⏸ Пауза: все позиции закрыты».
2. В кабинете Mubite запросить выплату (всё, что выше начального баланса, **кроме ~2 %** запаса: на $10k оставить ≈ $200).
   Если кабинет пишет про Funded Score (лучший день ≥ 40 % прибыли цикла) — выплату отложить: `bash ops/bot.sh resume` и повторить через неделю.
3. Дождаться, пока выплата **прошла** (баланс счёта уменьшился, обычно 24-48 ч). Во время проверки не торговать — бот стоит.
4. `bash ops/bot.sh resume` — бот учтёт уменьшение баланса как вывод (не убыток) и продолжит. В Telegram «💸 Учтено движение денег».

Чаще, чем раз в 28 дней, не надо (каждая выплата — 2 дня простоя и издержки закрытия), реже тоже не надо (прибыль на счёте его не увеличивает,
а дневной лимит фирмы считается от начального баланса — выросший счёт быстрее упирается в лимит).

## 7. Масштабирование (кнопка в кабинете)
Когда в кабинете доступно масштабирование (+10 % прибыли за 90 дней, выплаты считаются) — запросить его во время паузы выплаты (п. 6, шаг 2).
После одобрения размер счёта меняется — сообщить боту новый размер:
```
bash ops/stage.sh funded 12500
```
(подставить новый размер). Новый размер = новый «начальный баланс» для лимитов фирмы.

## 8. Переход $10k -> $200k
Когда накоплено ≈ $1 760 (цена $200k со всеми опциями — проверить на сайте):
1. Последняя выплата с $10k (п. 6), бот стоит на паузе.
2. Написать в поддержку Mubite о закрытии $10k-счёта (support@mubite.com), дождаться закрытия.
3. Купить Two-Step Pro $200 000 со всеми тремя опциями, создать **новый** демо-субаккаунт и ключ по инструкции Mubite.
4. `bash ops/stage.sh keys` (ключ нового субаккаунта), затем `bash ops/stage.sh phase1 200000` — бот начнёт с чистого состояния
   (пауза от старого счёта к новому не относится). Дальше — п. 5-7 с размером 200000.

## 9. Свой счёт Bybit (после выхода на funded $200k)
1. Один раз создать второго бота (спросит ключ своего счёта; права ключа: Read-Write, Unified Trading, **без права вывода**):
   ```
   bash ops/add_personal.sh
   ```
2. Перевести деньги на Unified-счёт Bybit, затем запустить (число = сколько USDT на счёте):
   ```
   UNIT=propsleeves-personal bash ops/stage.sh personal 5000
   ```
3. Состояние: `UNIT=propsleeves-personal bash ops/bot.sh status`.
- **Пополнять и выводить можно в любой момент без остановки бота** — он видит переводы в журнале Bybit и не путает их с прибылью/убытком
  (Telegram «💸 Перевод учтён»). Выводить только свободные деньги (не занятые маржой).
- Риск 1.5 %/день: по истории ≈ +47 %/год, худшая просадка ≈ 14 %. Бот сам остановится, если счёт упадёт на 25 % от пика.
- Минимум для старта — см. `docs/STATUS.md` (проверяется; ориентир $3-5 тыс.).

## 10. Что значат сообщения Telegram
| Сообщение | Что делать |
|---|---|
| «запущен» | ничего |
| «🎉 ФАЗА N ПРОЙДЕНА» | п. 5 |
| «🛑 ДНЕВНОЙ СТОП» | ничего: бот сам продолжит после 00:00 UTC |
| «🛑 ОБЩИЙ СТОП» | бот остановлен у пола фирмы. Ничего не трогать, прислать сообщение в чат |
| «✂️ Стоп по шорту …» | ничего (страховка от пампа монеты) |
| «⏸ Пауза…», «▶️ Пауза снята», «💸 Учтено…» | это ваши выплаты/переводы |
| «🔑 API-ключ истекает…» | продлить по ссылке из письма Mubite; если ключ поменялся — `bash ops/stage.sh keys`, затем `bash ops/bot.sh restart` |
| «⚠️ Цикл упал …» / «Ребаланс не выполнялся 2 дня» | `bash ops/bot.sh logs`, прислать вывод в чат |

## 11. Шпаргалка
```
bash ops/bot.sh status          # состояние
bash ops/bot.sh pause           # перед выплатой
bash ops/bot.sh resume          # после выплаты
bash ops/bot.sh logs            # лог
bash ops/stage.sh keys          # записать новые ключи (потом stage.sh … или bot.sh restart)
bash ops/stage.sh phase1 10000  # / trial / phase2 / funded <размер> / personal <USDT>
bash ops/deploy.sh              # обновить код бота из репо
```
